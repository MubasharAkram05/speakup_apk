# SpeakUp English - APK build

1. Create a free GitHub account and a new empty repository.
2. Upload ALL files from this folder (keep the .github folder).
3. Open the Actions tab, wait for "Build APK" to finish (about 5 minutes).
4. Open the finished run, download the artifact "SpeakUp-English-apk", unzip it.
5. Copy app-debug.apk to your phone and install it (allow "Install unknown apps").
